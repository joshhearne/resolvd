- **Ticket source:** every ticket records where it came from: web, email, email forwarded by an agent, phone call, SMS, Teams chat, scheduled ticket, API or monitoring alert. Agents pick it when logging a ticket, and you can filter the ticket list by it.
- **Due dates:** agents can give a ticket a due date, and check **Assign to me** when logging one.
- **SLA rules** (Admin → SLA policies): drop the resolve SLA when a ticket has a due date, and drop the response SLA when an agent creates a ticket and assigns it to themselves, optionally only for chosen sources.
