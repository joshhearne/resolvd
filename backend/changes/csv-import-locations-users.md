**CSV import for locations and users:** **Admin → Import** brings in company locations and users from a spreadsheet saved as CSV, with a sample file and an export of what's there now in the same format. Every upload is previewed row by row before anything is saved. New users can sign in with Microsoft, Google or a local password (with an optional invite email), so teams without SSO can be loaded in bulk too.
