- **Insert KB link** under the comment box: find an article, open it, and link straight to a PDF page and/or a highlighted phrase.
- **Target KB links** uses AI to point the KB links in a reply at the exact page and phrase, optionally as numbered steps. Every page and phrase is checked against the document.
- **Scope with knowledge** links the PDF version of an article when there is one, and lets you set a page or phrase per article.
- Local KB articles can have a source PDF attached (KB editor → **Source PDF**).
