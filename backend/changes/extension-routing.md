**Extensions at sites without extension dialing:** a location whose number doesn't take extensions can now name another location to dial them through (**Admin → Companies → Locations → Edit → Dial extensions here through**). Call buttons for people there dial that site's main line + their extension; with no site picked, their extension shows as **internal use only** instead of being dialled on a number that can't reach it.
